2026-11-17 통합 검증 스냅샷
이 소스는 중간 점검용이며 제품 완성/운영 배포를 의미하지 않습니다.
실제 외부 JEV 호출은 검증에서 제외했습니다. Windows VM은 네트워크 연결 해제 상태로 검증했습니다.
시험용 탐지/복구 기록을 실제 악성코드 대응 실적으로 사용하지 않습니다.
현재 상시 실행 구성은 observe-only이며 전체 자동 대응이 기본 활성화된 상태가 아닙니다.
최신 방화벽을 포함한 전체 A/B 정책 해제까지의 재검증, WFP 실제 패킷 검증, 장시간 안정성 검증은 남아 있습니다.
기존 문서는 작성 당시 상태를 설명하므로 본 날짜의 통합 검증 결과와 구분해 읽어야 합니다.

제공된 양방향 기본 차단/방향별 예외/add-remove 지원 소스를 기준으로 통합했습니다.
main/daemon.cpp에서 add/remove 방향 갱신, 전체 입력 검증 후 설정 변경, --protect 별칭을 수정했습니다.
C++ x64 Release 빌드 및 VM 실제 파이프의 잘못된 요청 거부/상태 불변 검증을 통과했습니다.
active 응답은 WFP 실제 패킷 차단의 독립 증거가 아닙니다. DNS 53 허용과 전역 예외 범위는 남아 있습니다.
실행 파일/빌드 중간 파일은 제외했습니다. CMakeLists.txt로 빌드할 수 있습니다.
